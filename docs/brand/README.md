# Kanda brand assets

The full brand book is the Kanda brand system: https://claude.ai/artifact/AyDi16xpft6YtNu32Rr5L5. It covers voice, words to use and avoid, colour and type tokens, logo rules, and the token profile texts for explorers and token lists. This folder holds the source files for the logo.

| File | Use |
| --- | --- |
| `kanda-mark.svg` | Basket-seal mark for light grounds: app icon, avatar, favicon |
| `kanda-mark-on-dark.svg` | The mark with a rim edge, for dark grounds |
| `kanda-lockup.svg` / `kanda-lockup-on-dark.svg` | Mark plus wordmark |
| `kanda-wordmark.svg` / `kanda-wordmark-light.svg` | Wordmark alone |
| `knd-256.png` | 256 × 256 token icon for wallets, explorers and token lists |
| `token-profile.md` | Ready-to-paste KND descriptions (one line, short, long) and where each goes |
| `kanda.tokenlist.template.json` | Token list with KND on Base and Base Sepolia; placeholders are filled after T0.6 |

The gold arc spans 108°, which is 30% of the ring, starting at 12 o'clock. That is the gold leg's share of KND's value at genesis. Don't rotate the mark or change the arc.

Token identity, matching `KandaToken` (L1 section 3.1): name `Kanda`, symbol `KND`, 18 decimals, Base. The name and ticker are working names until the P0 trademark and ticker clearance is done.
